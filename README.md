# あるもんで

公開中: https://arumonde-liart.vercel.app

手持ちの調味料と食材を登録しておき、「今日なに作る？」を AI やレシピサイトに聞くための Web アプリ。
アプリ自身はレシピを持ちません。在庫を覚えておくことと、いい質問文を作って渡すことだけをします。

## 使い方

1. **追加**: 持っている調味料・食材をタップ（約140品目のプリセット＋自由入力）
2. **棚**: 使い切ったら長押しで「切らした」。買い直したらタップで戻す
3. **探す**: 今日使う食材を選ぶ（もう一度タップで ★必ず使う、2つまで）→ 人数・時間・気分を選ぶ → 送り先を押す
   - ChatGPT / Claude / Perplexity: 質問文が入った状態で開く
   - Gemini: 質問文をコピーしてから開く（貼り付けて送信）
   - クックパッド / Google: ★の食材（なければ選んだ食材の先頭3つ）で検索

質問文には「手持ち以外の材料を使うなら『要買い足し』と明記して」と必ず入れています。

データはこの端末のブラウザ（localStorage）にだけ保存されます。ホーム画面に追加するとアプリのように使えます。

## 開発

```bash
pnpm install
pnpm dev     # http://localhost:5770
pnpm test    # src/lib の単体テスト
pnpm build
```

- `src/lib/` 純粋関数（正規化・プリセット・在庫・質問文・送り先・保存）
- `src/ui/` 3画面（棚・追加・探す）、`src/main.js` で配線。`window.__app` で状態を覗ける
